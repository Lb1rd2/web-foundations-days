About QuickNotes

QuickNotes is a simple app for capturing short notes the moment you think of them. It helps you stay organised by keeping your ideas, reminders, and to-dos in one place.

How to use QuickNotes

  1. Type your note into the input box.
  2. Press the Add note button to save it.
  3. Review your saved notes in the list.

Features

  • Create notes instantly
  • Keep all your ideas in one place
  • Simple, distraction-free layout

Keyboard shortcuts

Shortcut Action
Ctrl + N Create a new note
Ctrl + S Save the current note
Delete Remove the selected note
